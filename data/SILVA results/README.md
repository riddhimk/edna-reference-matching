# SILVA results

All outputs from the SILVA-based reference-matching experiments (full-length
baseline, plus the 16S V4 / 18S V9 region-specific follow-up) live in this
folder, kept separate from the MitoFish run in `../MitoFish results/`.

See `Explanation.md` in the project root (Parts 1 and 2) for what each file
means and how to read it. `src/config.py`'s default paths point here now;
every actual pipeline command in Explanation.md passes these paths
explicitly via environment variables regardless.
